# AGENTS.md — правила работы в zroute-s33

Сайт Server 33: рейтинги, хронология, форум, чаты, админ-панель.
Стек: чистые HTML/CSS/JS-модули + Supabase, без сборщика.

## Общение

- Язык: русский.
- Отвечать кратко: суть по делу, без лишних предисловий и самоповторов.
- Если задача двусмысленная — задать один-два уточняющих вопроса, а не гадать.
- Не коммитить и не пушить без явной просьбы пользователя.
- Комментарии в коде — только если пользователь их просит. В CSS-файлах
  проекта исторически есть поясняющие блоки — сохранять их стиль при правках.

## Сборка и проверки

- `node tests/contract.test.js` — 4004 проверки согласованности (обязательны после
  изменения кода/стилей). Перед сдачей убедиться: `Пройдено: 4004 Провалено: 0`.
- `node scripts/build-preview.mjs` — собирает `dist/preview.html` (38 страниц,
  стартовая — forum). Внутри поглядеть изменения, если надо визуально.
- `node scripts/build-admin-preview.mjs` — то же для админки.
- Другие скрипты: `scripts/*.mjs` (бэкап БД, sheet, миграции) — не трогать без задачи.

## Архитектура CSS — критично

Порядок подключения в `index.html` = приоритет (ниже перебивает выше при равной силе):

1. `src/styles-v8.css` — основной, ~сотни КБ, слои версий v6/v7/v8. Токены темы.
2. `src/forum.css` — форум, боковые вкладки (независим от рейтинга).
3. `src/mobile.css` — телефон, обязателен как «последнее слово» для узкого экрана.
4. `src/controls.css` — элементы ввода (select, checkbox, file).
5. `src/refine.css` — слой отделки, грузится **самым последним**.
   Туда кладём переопределения, которые должны выиграть каскад.

Изменения темы/полировки, которые обязаны перебить базовые правила, — в `refine.css`,
не в `styles-v8.css`. Токены обеих тем — в начале `styles-v8.css` (`:root` + `[data-theme="light"]`).

## Темы

- Тёмная — по умолчанию, токены `:root` в `styles-v8.css`.
- Светлая — селектор `[data-theme="light"]` на `<html>` (ставится в `src/main.js`).
- Светлая тема «бумажная»: крем внутри (`--bg #ece9e1`, `--surface #f7f4ec`),
  чернильный текст (`--text #2b2822`), терракотовый акцент (`--accent #c05a24`),
  эти тона заданы как токены — использовать их, а не хардкодить белые/чёрные.
- Тёмные «острова» (`.bot-hero`, `.role-card`, `.quart-page`) остаются тёмными
  и в светлой теме — у них свои тёмные токены.

## Коммиты и ветки

- Стиль сообщений — по истории: `type(scope): суть`, например
  `style(theme): ...`, `fix(ui): ...`, `feat(guides): ...`. Язык — русский.
- Коммитить только то, что относится к задаче. Не коммитить секреты.
- Ветки/PR — не создавать без просьбы; push — тоже.

## Знаковые места (карта)

- `src/main.js` — mount, переключатель темы, установка `data-theme` на `<html>`.
- `src/ui/helpers.js` — `esc`, `fmtDate`, `plural`, `deltaBadge`.
- `src/pages/*.js` — страницы (home, ladder, alliance, chats, forum и т.д.).
- `src/forum/contract.js` — контракт форума со стороны сервера.
- `src/admin/` — админ-панель, свой `admin.html` и `admin.css`.
- `supabase/*.sql` — миграции; они применяются пользователем вручную в Supabase.
- `sw.js` — service worker, кэширует статику; при новых версиях файлов поднять v-версии в `index.html` и bump в sw.js.
- `tests/contract.test.js` — контрактные проверки; там же строковые ассерты на стили (`forum.css`, шапка mobile и т.п.).

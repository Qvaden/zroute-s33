# Сервер 33 · Z Route: Redemption

Сайт сообщества 33 сервера игры **Z Route: Redemption**: форум игроков, рейтинг альянсов по итогам еженедельных VS, хронология захватов и защиты Столицы сервера, гайд для небольших альянсов.

**Сайт:** https://qvaden.github.io/zroute-s33/

Подробности об устройстве проекта — в папке [`docs/`](./docs).

Форум работает в черновом режиме, пока не подключена общая база — как её включить, описано в [`docs/FORUM.md`](./docs/FORUM.md).

Проверка: `node tests/contract.test.js`

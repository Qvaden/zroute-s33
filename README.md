# Сервер 33 · Z Route: Redemption

Сайт сообщества 33 сервера игры **Z Route: Redemption**: форум игроков, рейтинг альянсов по итогам еженедельных VS, хронология захватов и защиты Столицы сервера, гайд для небольших альянсов и справочник официальных гайдов игры — все 44 правила с картинками, перенесённые из Telegram-бота один в один.

**Сайт:** https://zroutehub.bond/

Подробности об устройстве проекта — в папке [`docs/`](./docs).

- [`HOSTING.md`](./docs/HOSTING.md) — где живёт сайт: GitHub → Render, домен и DNS у NicNames, сертификат и что делать при аварии.
- [`FORUM.md`](./docs/FORUM.md) — как включить форум и модерацию.
- [`MODERATION.md`](./docs/MODERATION.md) — роли, права, как дать мут и бан, как удалить чужой пост.
- [`MIGRATION.md`](./docs/MIGRATION.md) — переезд данных сайта в базу: вход по нику вместо токена GitHub, выдача прав редактора нажатием.
- [`ADMIN.md`](./docs/ADMIN.md) — работа в панели.
- [`ARCHITECTURE.md`](./docs/ARCHITECTURE.md) — почему сделано именно так.

Проверка: `node tests/contract.test.js`

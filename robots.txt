# Правила обхода для поисковиков.
#
# Сам сайт — одна страница с разделами в адресе (#/forum, #/ladder), поэтому
# роботу нужно свободно читать код в src/: без него он не сможет отрисовать
# разделы и увидит пустой документ. Закрыто только то, чего в выдаче быть
# не должно: панель управления, сырые данные, служебные скрипты, тесты и
# внутренние документы разработки.
#
# Исключение — справочник и снимки форума: каждый гайд справочника лежит
# отдельным файлом (handbook/<узел>/), каждая публичная тема — в forum/<id>/,
# гайд участника — в guides/<slug>/. У них два списка, потому что и источники
# разные: sitemap.xml пишет scripts/build-handbook-pages.mjs из дерева,
# sitemap-forum.xml — scripts/build-forum-pages.mjs из базы. Руками не
# ведутся ни тот, ни другой.
